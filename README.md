# แดชบอร์ดสำรวจโรคพิษสุนัขบ้า อำเภอปราสาท จ.สุรินทร์

ดึงข้อมูลสดจาก Google Sheets → ทำความสะอาดข้อมูลอัตโนมัติ → แสดงผลแบบโต้ตอบ (ภาษาไทย)

## วิธีใช้งาน
```bash
pip install -r requirements.txt
streamlit run app.py
```
เปิดเบราว์เซอร์ที่ http://localhost:8501

> Google Sheet ต้องตั้งค่าแชร์เป็น "ทุกคนที่มีลิงก์ดูได้" ข้อมูลรีเฟรชอัตโนมัติทุก 5 นาที (หรือกดปุ่ม 🔄)

## หน้าแดชบอร์ด
| หน้า | เนื้อหา |
|---|---|
| 📊 ภาพรวม | KPI ครัวเรือน/คน/สัตว์, ครัวเรือนที่ตอบสะสม, รายตำบล 18 ตำบล, สถานะวัคซีน |
| 🗺️ แผนที่ GIS | แผนที่สีรายตำบล เลือกตัวชี้วัดได้ 14 แบบ |
| 🧑‍⚕️ ประชากรและการถูกกัด | สัดส่วนผู้ถูกกัด/เคยฉีดวัคซีน รายตำบล/หมู่บ้าน + รายชื่อติดตาม |
| 🐶 สัตว์เลี้ยงและวัคซีน | ความครอบคลุมวัคซีนสุนัข/แมว เทียบเป้าหมาย 70%, รายการครัวเรือนเป้าหมาย |
| 🏘️ รายตำบล/หมู่บ้าน | ตารางสรุป, Treemap, ข้อมูลรายครัวเรือน |
| 🧹 คุณภาพข้อมูล | กฎทำความสะอาด, แถวที่ตัดออก, บันทึกการแก้ไขทุกค่า, ดาวน์โหลด CSV |

## โครงสร้าง
```
app.py                  # จุดเริ่มต้น + ตัวกรอง sidebar + เมนู
rabies/cleaning.py      # pipeline ทำความสะอาดข้อมูล (รันเดี่ยวได้: python -m rabies.cleaning)
rabies/ui.py            # โหลดข้อมูล, ธีม, KPI, การรวมข้อมูล
views/*.py              # หน้าต่างๆ
data/prasat_tambon.geojson  # ขอบเขต 18 ตำบล (จาก OpenGISData-Thailand)
scripts/build_geojson.py    # สร้าง geojson ใหม่จากไฟล์ระดับประเทศ
tests/smoke_test.py         # ทดสอบทุกหน้า
```
